# Attached

Attached helps you to attach to your running herdr sessions no matter when they
are running. **No network setup required!**

> [!WARNING]
> This project started as a full vibecoded app due to limitted access to my computer. 
> I'm currently in the process to de-slop it, so use it at your own risk!

## Install

Attached currently supports linux and macos devices. To install it run the command below:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://install.attached.sh | sh
```

Run ``attached --version`` to verify that the tool is ready to be used.
